Installation

Up and running in under 5 minutes.

1
 Copy module to your addons path Unzip and place the woo_connector folder inside your custom addons directory.
2
 Update module list & install Go to Apps → Update Apps List, search for WooCommerce Odoo Connector, click Install. Or via CLI:
./odoo-bin -u woo_connector -d your_database
3
 Create a WooCommerce Instance Go to WooSync → Configuration → Instances → New. Enter your store URL, Consumer Key, and Consumer Secret.
4
 Test Connection & Sync Click Test Connection, then use Sync Products, Sync Orders, or Sync Stock to run your first import.
5
 (Optional) Configure Webhooks In WooCommerce → Settings → Advanced → Webhooks, set the delivery URL to:
https://your-odoo.com/woo/webhook/order

Frequently Asked Questions

Common questions about setup, compatibility, and usage.

▸ Does it work with Odoo 19 Community Edition?
Yes. Fully compatible with both Odoo 19 Community and Enterprise. The OWL 2 dashboard, webhooks, and sync queue all work in Community without any Enterprise dependencies.
▸ How does SKU sync work?
WooCommerce SKUs are written to product.template.default_code on every sync run. If a SKU changes in WooCommerce, it is detected and updated in Odoo automatically. For single-variant products this also updates the product.product internal reference.
▸ Why is stock showing as 0 after sync?
Stock sync pushes Odoo on-hand quantities to WooCommerce. If your Odoo products have no stock (no stock.quant records), the pushed quantity is 0. Add inventory in Odoo via Inventory → Products → Update Quantity, then run Sync Stock again.
▸ Does it support WooCommerce variable products?
Yes. Variable products are fully supported. Each variant's SKU, price, and stock quantity are synced and mapped to Odoo product.product records.
▸ What happens if a sync fails?
Failed syncs are saved to the queue with the full error message. The cron retries them every 5 minutes, up to 5 attempts. You can also view and manually retry from Monitoring → Sync Queue.
▸ Is source code included?
Yes. You receive the complete Odoo module source (Python, XML, CSS, JS) under OPL-1. You can read, modify, and extend it freely to suit your business requirements.
