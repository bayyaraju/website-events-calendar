Install WooCommerce Odoo 19 Connector in 5 Minutes

From download to first WooCommerce order synced in under 5 minutes.

1
Copy module to your Odoo addons path Unzip and place the woo_connector folder inside your custom addons directory.
2
Update module list & install Go to Apps → Update Apps List, search WooCommerce Odoo Connector, click Install. Or via CLI:
./odoo-bin -u woo_connector -d your_database
3
Create a WooCommerce Instance in Odoo Go to WooSync → Configuration → Instances → New. Enter your WooCommerce store URL, Consumer Key, and Consumer Secret.
4
Test Connection & Run First WooCommerce Sync Click Test Connection, then use Sync Products, Sync Orders, or Sync Stock to run your first WooCommerce Odoo import.
5
(Optional) Configure WooCommerce Webhooks In WooCommerce → Settings → Advanced → Webhooks, set delivery URL to:
https://your-odoo.com/woo/webhook/order

Frequently Asked Questions — WooCommerce Odoo Connector

Common questions about setting up WooCommerce with Odoo 19.

Does this WooCommerce Odoo connector work with Odoo 19 Community Edition?
Yes. Fully compatible with both Odoo 19 Community and Enterprise. The OWL 2 dashboard, webhooks, and sync queue all work in Community without any Enterprise dependencies.
How does WooCommerce SKU sync to Odoo work?
WooCommerce SKUs are written to product.template.default_code on every sync run. If a SKU changes in WooCommerce, it is detected and updated in Odoo automatically. If you update the SKU in the Odoo WooCommerce product mapping, it is pushed back to WooCommerce on the next Sync Stock run.
Why is WooCommerce showing stock as 0 after syncing from Odoo?
Stock sync pushes Odoo on-hand quantities to WooCommerce. If your Odoo products have no stock records, the pushed quantity is 0. Add inventory via Inventory → Products → Update Quantity, then click Sync Stock again. Ensure Manage stock is enabled on the WooCommerce product side.
Does the WooCommerce Odoo integration support variable products?
Yes. WooCommerce variable products are fully supported. Each variant SKU, price, and stock quantity are synced and mapped to Odoo product.product records.
Can I connect multiple WooCommerce stores to one Odoo 19 database?
Yes. The connector supports unlimited WooCommerce store instances per Odoo database. Each store has its own credentials, warehouse, pricelist, and sync configuration.
What happens if a WooCommerce Odoo sync fails?
Failed syncs are saved to the queue with the full error message. The cron job retries them automatically up to 5 attempts. You can also view and manually retry from Monitoring → Sync Queue inside Odoo.
Is the WooCommerce Odoo connector source code included?
Yes. You receive the complete Odoo module source code — Python, XML, CSS, and JS — under OPL-1 license. You can read, modify, and extend it freely to match your business requirements.
