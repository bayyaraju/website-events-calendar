Technical Details

Simple to Install,
Built for Odoo 19

Drop it into your custom addons, install from Apps — done. No external packages, no npm, no build step.

Requirements

  • Odoo 19 (Community or Enterprise)
  • website_event module installed
  • website module installed
  • No external Python packages required
  • No npm or build tools required

Installation Steps

  • Copy module to your custom addons path
  • Restart the Odoo server
  • Go to Apps → search "Events Calendar View"
  • Click Install
  • Visit /events on your website to see it live

Module Dependencies

  • base — Odoo core framework
  • website — Website builder
  • website_event — Events module
  • Works alongside all other website modules

What Gets Added

  • Calendar / List toggle in Events page header
  • Monthly, weekly, and agenda calendar views
  • Event type filter chips on calendar page
  • No changes to existing list view behavior
