About This Theme

Not just a color swap.
A complete UI rethink.

Prox Professional hooks into Odoo 19's three-layer SCSS bundle hierarchy — overriding $o-* variables first, Bootstrap variables second, then appending visual CSS last. The result works with the framework, not against it. Stable across upgrades.

Built for finance teams, procurement managers, and operations leads who spend hours inside Odoo every day and need an interface that earns their trust.

Get Started

Installation

  1. Copy the theme_prox_professional folder into your Odoo custom addons path.
  2. Restart the Odoo server: sudo systemctl restart odoo
  3. Go to Settings → Apps and click Update App List.
  4. Search for "Prox Professional" and click Install.
  5. Hard-refresh your browser with Ctrl+Shift+R to flush cached assets.
  6. Done — the theme is now active globally across all backend views.
