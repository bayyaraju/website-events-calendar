About This Theme

Not just a color swap.
A complete UI rethink.

Prox Professional hooks into Odoo 19’s three-layer SCSS bundle hierarchy — overriding $o-* variables first, Bootstrap variables second, then appending visual CSS last. Works with the framework, not against it.

Built for finance teams, procurement managers, and operations leads who spend hours inside Odoo every day and need an interface that earns their trust.

Get Started

Installation

1 Copy theme_prox_professional to your Odoo custom addons path.
2 Restart: sudo systemctl restart odoo
3 Settings → Apps → Update App List
4 Search "Prox Professional" and click Install.
5 Hard-refresh: Ctrl+Shift+R to flush cached assets.
6 Done — theme is active globally, no further configuration needed.
