🔒 Secure by design

The assistant can only do what the logged-in user is allowed to do.

  • Every operation runs as the current user — access rights and record rules apply.
  • Private / technical methods and security models are blocked.
  • Writes and deletes can require confirmation.
  • Users only see their own chat sessions.
  • Module installs limited to Claude admins with Settings rights.
  • Each operation runs in a savepoint — a failure never breaks the request.

Frequently asked questions

Do I need an Anthropic API key?

Only for questions that need Claude. Quick actions, simple questions (show / count / list), order and invoice commands, app installs and cached answers work without a key and cost nothing.

Which Claude models are supported?

Claude Opus 5.5, Sonnet 5.5 (recommended), Haiku 4.5 and Fable 5.1 — plus any other model through the Custom Model ID field.

How much does the AI cost to run?

You pay Anthropic only for AI calls. Thanks to the local engine, answer cache and prompt caching, most requests use 0 tokens; the savings box shows the real figures.

Is my data safe?

Operations run with the logged-in user’s Odoo rights, technical models and private methods are blocked, and only the data needed for a question is sent to Claude.

Does it work with custom modules?

Yes. The assistant reads your installed models, so it can query and update custom models just like standard ones.

Is it available for Odoo Community and Enterprise?

Yes — Odoo 20.0 Community and Enterprise, on-premise and Odoo.sh.
