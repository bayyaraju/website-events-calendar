Technical Requirements

Simple to Install, Powerful to Use

Prerequisites

  • Odoo 19 (Community or Enterprise)
  • Anthropic API key (claude.ai)
  • Python 3.10+
  • pip install anthropic openpyxl
  • Internet access for Claude API

Module Dependencies

  • base (core Odoo)
  • web (frontend framework)
  • mail (messaging base)
  • No additional Odoo modules required
  • Works alongside all installed apps

Configuration

  • Install module via Settings → Apps
  • Go to Claude AI → Configuration
  • Enter your Anthropic API key
  • Select AI model (claude-sonnet-4-5 recommended)
  • Set optional system prompt for your business

Security & Permissions

  • Per-user session isolation
  • Role-based access control (Admin vs User)
  • Optional write-operation confirmation
  • Full session history and token tracking
  • API key stored securely in database
