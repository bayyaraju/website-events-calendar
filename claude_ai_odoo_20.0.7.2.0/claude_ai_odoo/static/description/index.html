🔒 Secure by design

  • Every operation runs as the current user — Odoo access rights and record rules apply.
  • Private / technical methods and security models are blocked.
  • Writes and deletes can require confirmation.
  • Users only see their own chat sessions.
  • Module installs restricted to Claude admins with Settings rights.
  • Each operation runs in a savepoint — a failure never breaks the request.
